# American Grade 9 Mathematics - Common Core

## Algebra I: expressions-equations

In Algebra I, students learn to write and solve equations with variables, which are letters that stand for unknown numbers. They practice using the order of operations to simplify expressions like 3(x + 2) and learn to combine like terms, such as adding 4x and 2x to get 6x. Students solve one-variable equations, like 2x + 5 = 15, by doing the opposite operation to both sides to find x. They also work with inequalities, using symbols like > and < to show relationships between numbers, such as solving x - 3 < 7 to find x < 10.

## Linear functions-systems

In ninth-grade math, you learn about linear functions, which are straight lines on a graph that show a steady change. A linear function can be written as an equation like y = mx + b, where ‘m’ is the slope (how steep the line is) and ‘b’ is where the line crosses the y-axis. You also learn how to solve systems of linear equations, which means finding where two lines meet or cross on a graph. For example, if one line is y = 2x + 1 and another is y = -x + 4, you can find the point where they intersect, like (1, 3). This helps you see where two different rules or situations have the same answer.

## Inequalities-absolute value

In ninth-grade math, you learn how to solve inequalities with absolute value, which are problems that have a number inside vertical bars, like |x|. The absolute value is a number’s distance from zero, so it’s always positive, and this means you split the inequality into two separate problems to solve. For example, |x + 3| < 5 becomes x + 3 < 5 and x + 3 > -5, and you solve both to find all the numbers that work. These inequalities can be written as compound inequalities, like -5 < x + 3 < 5, or graphed on a number line with shaded regions showing the solutions. You also practice checking your answers to make sure they fit the original inequality.

## Exponents-polynomials

In Grade 9 math, students learn to use exponents to show repeated multiplication, like writing 3 × 3 × 3 as 3³. They practice rules like adding exponents when multiplying powers with the same base, so 2⁴ × 2² = 2⁶, and subtracting exponents when dividing them, such as 5⁷ ÷ 5³ = 5⁴. Students also explore polynomials, which are expressions like 2x² + 3x + 1, and learn to add, subtract, and multiply them by combining like terms, such as simplifying (4x² + 2x) + (x² – 3x) to 5x² – x. These skills help students solve more complex algebraic problems and build a foundation for advanced math.

## Quadratics: solve-graph

In this unit, students learn to solve quadratic equations like x² – 4x + 4 = 0 by finding x-values that make the equation true. They practice factoring quadratic expressions, for example turning x² – 5x – 6 into (x – 6)(x + 1), to solve equations by setting each factor to zero. Students also graph quadratic functions, such as y = x² + 2x + 1, and recognize that their graphs are U-shaped curves called parabolas. They find key features of the graph, like the vertex (the lowest or highest point) and where the parabola crosses the x-axis. Students see how the equation’s numbers affect the graph’s shape and position, like how a negative sign flips the parabola upside down.

## Radical expressions

In ninth-grade math, students learn to work with radical expressions, which are numbers with a root symbol, like √9 or ∛27. They discover how to simplify radicals by finding perfect factors, such as turning √50 into 5√2, and how to add or subtract radicals that have the same number under the root, like combining 3√7 and 2√7 to get 5√7. Students also practice multiplying radicals, where √a × √b equals √(a × b), and dividing them, using rationalization to remove roots from the bottom of a fraction. Through these rules, they solve problems involving real-world measurements, like finding the side length of a square when its area is given as a radical.

## Functions: domain-range

In 9th-grade math, you learn that a function is a rule that connects one input to exactly one output, like a machine. The domain is all the possible inputs you can put into the function, such as the numbers 1, 2, and 3. The range is all the possible outputs the function gives back, like 4, 6, and 8 if the rule is to multiply by 2. You practice finding the domain by seeing which numbers work and the range by figuring out which results you get. For example, if the function rule is f(x) = x + 1, the domain could be 0, 1, 2, and the range would be 1, 2, 3.

## Data analysis-statistics

In Grade 9, students learn to interpret and compare data sets using dot plots, histograms, and box plots. They calculate measures of center, like the mean, median, and mode, as well as measures of spread, such as the range and mean absolute deviation to describe a data distribution. Students use these concepts to decide which center is best for a set of data, like finding the median for household income because extreme values can skew the mean. They also investigate patterns and trends in bivariate data by creating scatter plots and using lines of best fit to make predictions about future events, such as estimating a test score based on study hours.
