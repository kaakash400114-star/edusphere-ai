# ICSE Class 12 Mathematics - CISCE

## Algebra and calculus core
Matrices-determinants and systems; inverse trigonometric functions; continuity-differentiability; applications of derivatives: maxima-minima-tangents; integrals: indefinite-definite and properties; differential equations: variable separable-linear.

## Vectors-3D-probability
Vector algebra: dot-cross, applications; lines-planes in 3D: angles-distances; probability: conditional-Bayes; distributions: binomial idea; linear regression-correlation (statements).

## Applications
Linear programming problems: feasible regions, corner-point optimisation; word-problem modelling across all chapters.
